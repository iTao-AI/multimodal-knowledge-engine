# v0.1.7 Bounded Release Design

Date: 2026-09-01

Status: approved for implementation; this document records the public-neutral release-prep
boundary, not publication evidence.

## Outcome

Prepare a source release candidate for Multimodal Knowledge Engine `v0.1.7` from the approved
current default-branch snapshot. The release freezes already merged behavior and documentation;
it does not introduce product behavior, runtime architecture, provider use, deployment, or
package-registry publication.

The approved starting identity is commit
`553e6b86675bc3809dee47949f60dd1b73dfb54e` with tree
`93799bdace8702c44fc39fd6b2756bcc2bd59a2a`.

## Included facts

- The native synthetic Evidence workspace projection and its provider-free proof surface.
- Supported dependency-line and `setup-uv` maintenance already present on the default branch.
- Lock-bound installed-wheel consumer proof.
- MCP consumer normal no-match, capped non-exhaustive selection, inactive Evidence recovery, and
  the corresponding recovery showcase.
- Default-branch and stable-release documentation truth alignment.
- The current `search_library_v2` CJK active-scan budget-error mapping and installed-wheel recovery
  proof.

## Contract boundaries

The exact ten-tool MCP v1 inventory, SQLite/Publication authority, active-Publication-only reads,
fail-closed recovery, synthetic/provider-free proof, and comparison-only retrieval evaluations
remain unchanged. No MCP 2 surface, OCR or retrieval runtime promotion, HTTP/UI work, fixture or
holdout rewrite, new provider, PyPI publication, deployment, or quality/performance/adoption claim
is part of this release boundary.

Historical release records, including the published `v0.1.6` note, remain byte-identical.

## Release-prep boundary

This phase updates project-owned release identity, current release documentation, exact wheel
examples, release scripts, and their tests. It ends after a clean local commit and a
`READY_FOR_AUTHORITY_REVIEW` handoff. Tag creation, GitHub Release publication, public archive
verification, and cleanup are separate authorized gates after review.
