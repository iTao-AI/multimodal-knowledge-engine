## Contract boundaries

The exact ten-tool MCP v1 inventory, SQLite/Publication authority, active-Publication-only reads,
fail-closed recovery, synthetic/provider-free proof, and comparison-only retrieval evaluations
remain unchanged. No MCP 2 surface, OCR or retrieval runtime promotion, HTTP/UI work, fixture or
holdout rewrite, new provider, PyPI publication, deployment, or quality/performance/adoption claim
is part of this release boundary.

Historical release records, including the published `v0.1.6` note, remain byte-identical.

## Release-prep boundary

This phase updates project-owned release identity, current release documentation, exact wheel
examples, release scripts, and their tests. It ends after a clean local commit and a
`READY_FOR_AUTHORITY_REVIEW` handoff. Tag creation, GitHub Release publication, public archive
verification, and cleanup are separate authorized gates after review.

## Terminal sequence

The release truth sequence is:

`release-prep PR` → `exact-main gates/tag/Release/archive proof` → `same-scope post-publication docs closeout PR`.

The release-prep PR may record only current source and candidate evidence. It must not prefill a
future tag object, target commit, Release ID, timestamp, archive identity, or publication result.
After the release-prep change is reviewed and merged, the owning gate runs the complete exact-main
checks, creates the annotated tag and GitHub Release only with explicit authorization, and verifies
the public source archive.

After those facts exist, the same release scope must replace the pre-publication record and stale
release-prep surfaces in a post-publication docs closeout PR. Its `Publication verification` record
must contain the real annotated tag object SHA, tag target commit, merge commit/tree, GitHub Release
ID/URL/timestamp/state/assets, archive filename/bytes/SHA-256, archive manifest SHA-256 and
manifest/tree equality, candidate wheel and receipt identity, hosted checks, exact-main proof,
archive smoke, and explicit non-claims. That closeout then requires its reviewed HEAD, hosted CI,
squash merge, exact-main checks, and task-owned cleanup to be read back before terminal closeout.
