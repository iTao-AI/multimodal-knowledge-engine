## Terminal sequence

The release truth sequence is:

`release-prep PR` → `exact-main gates/tag/Release/archive proof` → `same-scope post-publication docs closeout PR`.

The current `v0.1.7` note and release-prep surfaces remain policy-only until publication facts
exist; they must not prefill future identity. Once the annotated tag, exact-main result, GitHub
Release, and public archive facts exist, the closeout PR replaces those surfaces with a real
`Publication verification` record containing the annotated tag object SHA, tag target commit, merge
commit/tree, GitHub Release ID/URL/timestamp/state/assets, archive filename/bytes/SHA-256,
manifest/tree equality, wheel and receipt, hosted checks, exact-main proof, archive smoke, and
explicit non-claims. The closeout
also requires reviewed HEAD, hosted CI, squash merge, exact-main readback, and authorized cleanup.
