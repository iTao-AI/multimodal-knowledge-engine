## Terminal sequence

The release truth sequence is:

`release-prep PR` → `exact-main gates/tag/Release/archive proof` → `same-scope post-publication docs closeout PR`.

The current `v0.1.7` note and release-prep surfaces remain policy-only until publication facts
exist; they must not prefill future identity. Once the annotated tag, exact-main result, GitHub
Release, and public archive facts exist, the closeout PR replaces those surfaces with a real
`Publication verification` record in the release note and a matching `Completed v0.1.7 Release
Record` in `verify-release.md`. The fixed inventory contains the release-prep PR number/URL,
reviewed HEAD/tree, merge commit/tree, reviewed tree == merge tree, annotated tag object SHA, tag
target/tree, GitHub Release ID/URL/timestamp/state/assets, Release body SHA-256 and tagged
release-note SHA-256 values, archive filename/bytes/SHA-256, archive manifest SHA-256 and positive manifest/tree
equality, candidate wheel and receipt identity, closed positive checks, archive smoke, Git-less values, and
explicit non-claims. Both records must agree on all immutable facts; the inventory has no
post-closeout PR or cleanup self-reference. The closeout also requires reviewed HEAD, hosted CI,
squash merge, exact-main readback, and authorized cleanup.

The closed values are `status=passed; head=<sha>; checks=<n>/<n>`,
`status=passed; merge=<sha>; checks=<n>/<n>`, `status=passed; merge=<sha>; proof=exact-main`,
`status=equal; tree=<sha>`, `status=passed; source=public-github-archive`, and
`status=passed; scope=allowlist`; each check binds the stated reviewed HEAD or merge commit.
